# Contributing

Work begins with a GitHub issue containing clear acceptance criteria. Use a short branch name such as `feat/12-personalized-greeting` or `fix/27-duplicate-submit`.

Keep pull requests focused. Complete the PR template, keep the PR in draft while implementation changes are expected, and do not merge until all gates in `docs/workflow.md` are satisfied.

Conventional commit prefixes are encouraged: `feat`, `fix`, `test`, `docs`, `chore`, and `refactor`.
