# Architecture decision register

This register distinguishes implemented contracts, accepted rationale and genuinely unresolved policy. Stable IDs remain useful for decision references; delivery sequencing and acceptance status belong on GitHub. Read the [ADR index](README.md), current [application guide](../README.md), and the owning issue before changing a policy. Source implementation does not prove a hosted deployment or provider setting.

Household aggregation requires current authorized eligibility. No cross-group settlement or netting is approved; zero aggregate net does not settle nonzero original-space obligations. Every individual's source-group net must be zero for that group to be settled. Partial or failed reads cannot imply settlement. ADR-008 preserves the rationale for the superseded pair policy; it is not current authorization.
