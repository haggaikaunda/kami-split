# Production navigation and source restoration

The root goes directly to `/sign-in` when signed out and to `/groups` for a verified session. [Web authentication routing](../application/web-auth-routing.md) guards application pages before rendering and rechecks browser session/history transitions. Groups is the complete authenticated Group/Trip directory with URL-backed All / Groups / Trips selection (`/groups?kind=groups` or `kind=trips`). The Trips selection retains All / Upcoming / Past date filtering (`filter=upcoming` or `past`); legacy `/trips` discovery links redirect with their selection and source restoration parameters. Every Trip workspace is `/trips/:groupId`, with independent financial and authorization boundaries. Household provides five workspace tabs from `/household`, with its Expenses ledger at `/household/expenses`. Designated creator entry uses `/groups/new` or `/trips/new` with independent Group/Trip recovery. Account, invitation and Auth routes use real configured services.

`FinancialSession` is the only root financial provider. `ScopedLink`, `SourceReturn` and `RestoreSource` in `components/groups/navigation.tsx` retain actor-scoped visits, filter URLs, scroll and logical focus. Restoration runs after a complete source read under the [bounded Relay reuse policy](workspace-loading.md); missing/ineligible targets fall back to the current heading. Logout/account changes dispose the scope and prevent old responses or source visits from populating another session.

Ordinary-group details use `/groups/:groupId/expenses/:expenseId` and repayments use `/groups/:groupId/repayments/new`; Trips use the equivalent `/trips/:groupId` paths. Original Household ledger/details/repayments use `/household/ledger` within its single dedicated navigation frame. Groups discovery excludes the designated Household; authorized legacy group links replace to the canonical family. Drafts and uncertain attempts use the existing account/group-scoped sessionStorage contracts, never global preview draft routes. See the [authenticated journey](../application/relay-expenses.md#discovery-and-return-navigation-105).

The seeded global shell, preview providers, intercepting `@detail` slot and its old routes were retired in #184. They are not compatibility routes; unsafe legacy resource IDs receive normal not-found behavior. Original #17 navigation evidence is available in [Git history](https://github.com/haggaikaunda/kami-split/blob/225780b/docs/navigation/README.md) only.

See [authorized workspace loading](workspace-loading.md) for the destination request matrix, persistent frames, intent ownership, foreground invalidation and Household compatibility contract introduced by #193.

The compact shared header retains the approved Household/Trip artwork and shows Kami Grow above the current destination. Household and Groups flank the mobile Add expense action; trips stay under Groups. The Profile avatar opens `/account` and records the exact actor-scoped source visit. Profile Back and browser Back restore authorized source state, including ledger filters, loaded extent, scroll and logical focus. Direct Profile entry returns safely to Groups. Workspace More discloses Activity and Members with native links, current selection, keyboard access and Escape focus restoration. Global expense entry opens the existing Household ledger source chooser without selecting the first space; a Group/Trip uses its freshly authorized source. The later Personal-enabled navigation extension remains owned by #253.
