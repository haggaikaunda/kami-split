# Production navigation and source restoration

The root goes directly to `/sign-in` when signed out and to `/groups` for a verified session. [Web authentication routing](../application/web-auth-routing.md) guards application pages before rendering and rechecks browser session/history transitions. Group and Trip discovery use real authenticated membership reads; every Trip workspace is `/trips/:groupId`, with independent financial and authorization boundaries. Household provides five workspace tabs from `/household`, with its Expenses ledger at `/household/expenses`. Designated creator entry uses `/groups/new` or `/trips/new` with independent Group/Trip recovery. Account, invitation and Auth routes use real configured services.

`FinancialSession` is the only root financial provider. `ScopedLink`, `SourceReturn` and `RestoreSource` in `components/groups/navigation.tsx` retain actor-scoped visits, filter URLs, scroll and logical focus. Restoration runs after a complete source read under the [bounded Relay reuse policy](workspace-loading.md); missing/ineligible targets fall back to the current heading. Logout/account changes dispose the scope and prevent old responses or source visits from populating another session.

Ordinary-group details use `/groups/:groupId/expenses/:expenseId` and repayments use `/groups/:groupId/repayments/new`; Trips use the equivalent `/trips/:groupId` paths. Original Household ledger/details/repayments use `/household/ledger` within its single dedicated navigation frame. Groups discovery excludes Household and Trips; authorized legacy group links replace to the canonical family. Drafts and uncertain attempts use the existing account/group-scoped sessionStorage contracts, never global preview draft routes. See the [authenticated journey](../application/relay-expenses.md#discovery-and-return-navigation-105).

The seeded global shell, preview providers, intercepting `@detail` slot and its old routes were retired in #184. They are not compatibility routes; unsafe legacy resource IDs receive normal not-found behavior. Original #17 navigation evidence is available in [Git history](https://github.com/haggaikaunda/kami-split/blob/225780b/docs/navigation/README.md) only.

See [authorized workspace loading](workspace-loading.md) for the destination request matrix, persistent frames, intent ownership, foreground invalidation and Household compatibility contract introduced by #193.
