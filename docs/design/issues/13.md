# Implement trip overview and trip-expense browsing

## User outcome

Users inspect what a trip cost, each member’s share/contribution and the expenses behind it.

## References

- [ux-spec.md#t01t02t03-trips](../ux-spec.md#t01t02t03-trips)
- [screen-flows.md#n05-trip-chain](../screen-flows.md#n05-trip-chain)

## Included behavior

Trip metrics, Overview/Expenses tabs, day-grouped searchable/category-filtered list, add-expense association and household repayment entry.

## Exclusions

No separate trip debt settlement, budgets, itinerary, notes planner or chart implementation duplicated from next issue.

## Acceptance criteria

- [ ] Maui total $1,644.20 and member paid/share $822.10 each; trip and household reference identical expense IDs.
- [ ] Expense list groups by effective date and filters description/category; detail Back restores tab/filter/scroll/focus and refreshes changed records.
- [ ] Add from trip preselects association and editable suggested date. Pre-trip booking dates are allowed and included in total.
- [ ] Trip repayment explicitly affects household balance; new/empty/inaccessible trips have useful states.
- [ ] Three-member contributions wrap without fixed pair assumptions; place daily/category charts for chart issue without fake values.

## Mobile, desktop and accessibility

Apply the shared responsive/accessibility rules: phone-first, desktop context preserved, keyboard operation, labels/errors, 44px targets, visible focus, non-color status and correct focus restoration. Verify the relevant journey at 390px and 1280px; no clipped controls at 320px or 200% text.

## Required tests

Integration/E2E P07 and N05 with create/add/edit/remove association/delete/repay; assert no double count and trip filters preserved after mutation. Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`; obtain independent testing and final-diff review per AGENTS.md.

## Edge states

Cover relevant loading, empty, filtered-empty, invalid input, denied/unavailable, pending, failed and stale states with named seed scenarios. Do not show a fake zero balance while loading or rely on a toast as proof of mutation.

## Dependencies and readiness

Blocked until the design/documentation PR is reviewed and merged, stable main references are verified, and this issue is approved. Depends on UX-01, UX-02, UX-03, UX-04, UX-06, UX-07, UX-10, UX-12. Existing pilot issues #6–#9 are separate and not prerequisites.
