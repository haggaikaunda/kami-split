# Build responsive shell and context-aware navigation

GitHub issue: [#17](https://github.com/haggaikaunda/kami-split/issues/17). Parent: [#13](https://github.com/haggaikaunda/kami-split/issues/13). Design gate: [PR #12](https://github.com/haggaikaunda/kami-split/pull/12).

## User outcome

Users can move between screens and return to the precise working context they left.

## References

- [screen-flows.md](../screen-flows.md)
- [ux-spec.md#scope-and-screen-inventory](../ux-spec.md#scope-and-screen-inventory)

## Included behavior

Four destinations, account entry, canonical expense route, per-history-entry source descriptors, responsive panel/page presentation, dirty-exit infrastructure and logical focus/scroll restoration.

## Exclusions

No financial journey logic or auth provider; shell may use placeholder content until dependent issues implement routes.

## Acceptance criteria

- [ ] Desktop side nav / phone bottom nav expose Overview, History, Trips, Household; active state and headings are accessible.
- [ ] Contextual desktop expense entry pushes one panel route; direct link/phone uses full page. Open full page replaces presentation without extra Back step.
- [ ] Back/Forward, close/Escape and repeated same-ID visits preserve independent source filters/tab/chart scope/period/scroll/focus; direct link has safe in-app fallback.
- [ ] Resize changes presentation without losing record/draft/request or adding history. All dirty exits—including browser navigation—confirm or preserve changes.
- [ ] Return contexts contain serializable descriptors, not cached HTML, mutable DOM nodes or onclick strings. Mutation returns requery current data.

## Mobile, desktop and accessibility

Apply the shared responsive/accessibility rules: phone-first, desktop context preserved, keyboard operation, labels/errors, 44px targets, visible focus, non-color status and correct focus restoration. Verify the relevant journey at 390px and 1280px; no clipped controls at 320px or 200% text.

## Required tests

Router integration/E2E shell fixtures for N01/N02/N04/N05/N07, direct link, Back/Forward, repeated origin, resize and dirty discard/keep. Test focus and scroll with synthetic routes before features land. Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`; obtain independent testing and final-diff review per AGENTS.md.

## Edge states

Cover relevant loading, empty, filtered-empty, invalid input, denied/unavailable, pending, failed and stale states with named seed scenarios. Do not show a fake zero balance while loading or rely on a toast as proof of mutation.

## Dependencies and readiness

Blocked until the design/documentation PR is reviewed and merged, stable main references are verified, and this issue is approved. Depends on [#16](https://github.com/haggaikaunda/kami-split/issues/16). Existing pilot issues #6–#9 are separate and not prerequisites.
