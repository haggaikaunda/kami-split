# Complete fault recovery across seeded financial journeys

## User outcome

Users recover from failures without losing drafts or creating financial duplicates.

## References

- [ux-spec.md#r01-shared-states](../ux-spec.md#r01-shared-states)
- [data-access.md#mutations-retries-and-concurrency-without-a-database](../data-access.md#mutations-retries-and-concurrency-without-a-database)
- [screen-flows.md](../screen-flows.md)

## Included behavior

Cross-journey integration of existing typed failure states and deterministic demo scenarios; individual features must already handle their own errors.

## Exclusions

No database or network stack; no postponement of feature-level validation until this issue; no bypass of repository security requirements.

## Acceptance criteria

- [ ] Exercise real adapter loading/empty/denied/failure/conflict outcomes; recovery gallery is a discoverability aid, not a fake success path.
- [ ] Unknown completion queries/resolves original request; retry cannot double-apply expense, repayment or deletion.
- [ ] Stale edit compares original/latest/draft; concurrent deletion and expired access retain private draft appropriately and prevent accidental recreation.
- [ ] Browser navigation, Escape and resize during dirty/in-flight forms preserve safe state; old async query results cannot replace newer screen data.

## Mobile, desktop and accessibility

Apply the shared responsive/accessibility rules: phone-first, desktop context preserved, keyboard operation, labels/errors, 44px targets, visible focus, non-color status and correct focus restoration. Verify the relevant journey at 390px and 1280px; no clipped controls at 320px or 200% text.

## Required tests

Failure-focused E2E P10 and N02/N03/N06/N07, second-client/version fixture, pre/postcommit failures, route races and response ordering with ledger/event assertions. Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`; obtain independent testing and final-diff review per AGENTS.md.

## Edge states

Cover relevant loading, empty, filtered-empty, invalid input, denied/unavailable, pending, failed and stale states with named seed scenarios. Do not show a fake zero balance while loading or rely on a toast as proof of mutation.

## Dependencies and readiness

Blocked until the design/documentation PR is reviewed and merged, stable main references are verified, and this issue is approved. Depends on UX-02, UX-04, UX-06, UX-07, UX-08, UX-09, UX-10, UX-11, UX-13, UX-15, UX-16. Existing pilot issues #6–#9 are separate and not prerequisites.
