## Included behavior

Final cross-screen verification and bounded accessibility/responsive fixes; feature PRs still need their own tests.

## Exclusions

No new product features, broad restyling, production auth/persistence claims or merging without required workflow gates.

## Acceptance criteria

- [ ] Trace P01–P10 and N01–N07 to passing tests/manual evidence; compare equivalent seed state and viewport, not arbitrary screenshots.
- [ ] Verify 320/390/768/1280px, 200% text, phone keyboard/safe areas, keyboard-only dialogs/charts/forms and screen-reader labels/status/focus.
- [ ] Check direct links, Back/Forward, repeated same-ID sources, filtered origins, chart mutation return, dirty resize and unavailable/tombstone routes.
- [ ] Record contrast, target sizes, reduced motion, fallback assets and truthful chart scales; resolve blocking defects through their owning issues.
- [ ] Required repository checks pass; independent tester and final-diff reviewer results are recorded before rollout completion.

## Mobile, desktop and accessibility

Apply the shared responsive/accessibility rules: phone-first, desktop context preserved, keyboard operation, labels/errors, 44px targets, visible focus, non-color status and correct focus restoration. Verify the relevant journey at 390px and 1280px; no clipped controls at 320px or 200% text.

## Required tests

Critical-path browser suite plus automated accessibility checks and manual VoiceOver/TalkBack-equivalent review; attach screenshots, routes, seed/clock and criterion-to-test matrix. Run `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`; obtain independent testing and final-diff review per AGENTS.md.

## Edge states

Cover relevant loading, empty, filtered-empty, invalid input, denied/unavailable, pending, failed and stale states with named seed scenarios. Do not show a fake zero balance while loading or rely on a toast as proof of mutation.

## Dependencies and readiness

Blocked until the design/documentation PR is reviewed and merged, stable main references are verified, and this issue is approved.
