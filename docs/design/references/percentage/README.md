# Percentage visual reference

The owner-provided [full-resolution concept](concept-reference.png) informs percentage fields, adjacent exact amounts, validation and saved intent. See [the Percentage contract](../../../application/percentage-splits.md) and [collaborative editing](../../../application/expense-editing.md) for implemented behavior. Current Light/System/Dark and system typography follow the [UI guide](../../../application/ui.md); the concept does not establish a light-only application.

The image is an approved design input, not a rendered implementation result. Names and amounts are illustrative; preserve current routes, source ownership and supported split modes. Run `scripts/percentage-browser.cjs` against an isolated production preview with an external Playwright installation (`PLAYWRIGHT_MODULE`); outputs default to `/tmp/kami-percentage-browser`. Synthetic responses do not establish server authorization or persistence. Results and historical captures belong on [#199](https://github.com/haggaikaunda/kami-split/issues/199).
